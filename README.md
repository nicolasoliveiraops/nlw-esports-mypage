# NLW eSports

This project is from my earlier HTML and CSS studies with Rocketseat. It's a course exercise, kept here as part of my learning history.

A learning project built during Rocketseat's NLW eSports event to create a personal page featuring games, series, and favorite streamers.

This is a static HTML and CSS page based on the event's lessons, with personal content added to the original exercise.

## Skills practiced

- HTML page structure
- CSS layouts with Flexbox
- Pseudo-classes and visual effects
- Animations with transform and transition

## View the project

[GitHub Pages demo](https://nicolasoliveiraops.github.io/nlw-esports-mypage/)

## Run locally

Clone or download this repository and open `index.html` in a browser. No build step is required.
